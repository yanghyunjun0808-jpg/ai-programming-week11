# week12 — scores_2026 데이터 정제와 반별 비교

## 데이터 출처
- 수업에서 제공받은 `scores_2026.csv`

## 행 수
- 원본 114행 → 정제 후 100행 (빈 점수 6, 중복 4, 범위 밖 4행 제거)

## 열 설명
- 학번: 학생 식별 번호
- 이름: 학생 이름
- 반: 1반 / 2반
- 과목: 수학 / 영어 / 프로그래밍
- 점수: 과목별 시험 점수 (0~100점)

## 빈 칸 처리
- 점수가 빈 행은 **지웠다**. 점수가 없는 행은 평균에 넣을 수 없고,
  0점으로 채우면 실제보다 평균이 낮아지기 때문이다.
